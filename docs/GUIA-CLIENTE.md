# Guia do cliente — Centro de Comando

## Instalar (5 minutos)
1. Abra o link que você recebeu, **com a sua conta Google**, e clique em **Fazer uma cópia**.
2. Na planilha copiada, espere aparecer o menu **⚙ Centro de Comando** (uns segundos).
3. Clique em **⚙ Centro de Comando → 🔑 Ativar licença**.
4. O Google vai pedir permissão (só na primeira vez):
   **Continuar → escolha sua conta → Avançado → Acessar Centro de Comando → Permitir**.
   Isso é necessário para o painel salvar no **seu** Drive.
5. Clique de novo em **🔑 Ativar licença** e digite a chave que você recebeu.

## Usar
- **⚙ Centro de Comando → ▶ Abrir painel**.
- Tudo o que você digita fica salvo nesta planilha (na aba oculta `_banco`). Não apague essa aba.
- Arquivos enviados e downloads ficam na pasta **Centro de Comando — arquivos do painel** no seu Drive.
- Quem você compartilhar a planilha (como Editor) vê e edita os mesmos dados.

## Backup
O painel faz backup sozinho todo dia. Para voltar um dia: menu **⚙ Centro de Comando → ♻ Restaurar um backup**.

## Ligar as suas planilhas (aba "Fontes")
Algumas abas do painel leem planilhas do Drive (escala, numerador, HTs, inventário…).
1. Abra a aba **Fontes**.
2. Na coluna **C**, cole o ID da **sua** planilha correspondente (o trecho do endereço entre `/d/` e `/edit`).
3. Feche e abra o painel de novo.

## Problemas comuns
| Aparece… | O que fazer |
|---|---|
| "Licença não ativada" | Menu ⚙ → 🔑 Ativar licença. |
| "Licença bloqueada" ou "venceu" | Fale com quem te vendeu. |
| "Esta chave já está em uso" | A chave já foi ativada em outra planilha. Peça para liberar. |
| O menu ⚙ não aparece | Recarregue a página da planilha e espere 10 segundos. |
| Painel desatualizado | Menu ⚙ → 🔄 Baixar versão nova do painel. |
